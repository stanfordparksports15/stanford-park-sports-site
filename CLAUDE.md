# Stanford Park Youth Sports website

Live at https://www.stanfordparksports.com. Owner: Petr Ropek (GitHub `stanfordparksports15`). Javi (`javisps1`) helps as a collaborator.

## How the site works

- Plain static HTML. **Netlify auto deploys every push to `main`** (live about a minute later). There is no build step on Netlify; it publishes this folder as is (`netlify.toml`).
- The pages (`index.html`, `about.html`, `programs.html`, `schools.html`, `get-involved.html`, `donate.html`, `contact.html`) are **generated**. Never hand edit them. Change `tools/build.py`, then run:

  ```bash
  python3 tools/build.py
  ```

  It needs Pillow (`pip3 install pillow`). It also rewrites `_redirects`, `robots.txt` and `sitemap.xml`.
- Styles: `assets/css/styles.css` (color and font tokens at the top). Behavior: `assets/js/site.js`.
- The machine runs Python 3.9: no backslashes inside f-string `{}` expressions (put the string in a variable first).

## Common edits (all in `tools/build.py`)

| Change | Where |
|---|---|
| Add, edit or remove a program card | `PROGRAMS` list. Tuple: (school, sport key, title, day, dates, time, location, note, price, registration URL). Register buttons go straight to the Fillout form URL in the last field. |
| School logo on a program card | Put a `.webp` in `assets/img/logos/` and map the school name in `PROGRAM_LOGOS` |
| Contact info, donate link, EIN | Constants near the top: `EMAIL`, `PHONE_DISPLAY`, `PHONE_TEL`, `ADDRESS`, `DONATE_URL`, `EIN` |
| Partner school names and logos | `SCHOOLS`, `LOGOS` (files in `assets/img/logos/school-NN.webp`) |
| Sports, FAQ, testimonials, safety copy | `SPORTS`, `FAQ`, `TESTIMONIALS`, `SAFETY` |
| Page copy | the function for that page: `home()`, `about()`, `programs()`, `schools()`, `donate()`, `get_involved()`, `contact()` |
| Photos | `assets/img/pNNNN-800.webp` and `-1600.webp` (NNNN = last four digits of the original file). Make both sizes. |

The contact form uses Netlify Forms (`data-netlify="true"`). Submissions show up in Petr's Netlify dashboard under Forms.

## Rules

- **Desktop design is approved.** For phone fixes, put CSS inside the existing `@media (max-width: 960px)` blocks so desktop does not change.
- **Registration is Fillout only.** Don't add "Already registered? Pay online" links. The Stripe links in `STRIPE_LINKS` are kept but not shown.
- **Do not touch the domain's DNS, MX or TXT records** on Wix. Email depends on them.
- **This repo is public and every file in it is published on the site.** Never commit private material: pricing proposals, school pitch decks, contracts or parent data. Those live outside the repo or in `.gitignore` (for example `flyer/ycis/`).
- `flyer/` holds print flyers generated by the other scripts in `tools/` (`flyer.py`, `cheer_flyer.py`, `bentley_flyers.py`, `khan_schedule.py`, `overview_slide.py`). To make a PDF, open the HTML in headless Chrome with `--print-to-pdf`.

## Before you push

1. Run `python3 tools/build.py` and confirm it finishes with no errors.
2. Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000. Check the page you changed on desktop and at phone width.
3. Commit with a short message that says what changed (for example `Programs: add Lakeside winter soccer`), then `git push`. Check the live site a minute later.
